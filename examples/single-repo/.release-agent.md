## Release notes style

Keep release notes concise and audience-friendly. Lead with the headline change in plain language; leave the technical changelog for the second half. Avoid marketing hype — describe what changed and why someone reading should care.

## Custom context

Anything you put under this heading is passed verbatim to the AI when it drafts the release narrative. Use it for team conventions, terminology, audience hints, or "always mention X when Y changes" rules. Tagline does not interpret this text; it's purely model context.
